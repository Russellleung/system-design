DAG graph"To handle complex pricing cascades without rounding drift, I designed a high-precision Delta Adjustment DAG Engine using BigDecimal throughout. The calculation engine models metric dependencies as a Directed Acyclic Graph, where graph topologies are dynamically loaded using a Factory pattern and configured via two dictionaries: one defining key-to-children dependency structures, and another mapping nodes to functional interfaces that encapsulate the update logic. When an input delta changes, updates cascade through the DAG via a memoized traversal—preventing infinite recursion and eliminating redundant evaluations of shared subgraphs. This design decoupled calculation rules from execution mechanics, allowing us to easily introduce or reconfigure trading strategy graphs in code without altering core engine infrastructure."
